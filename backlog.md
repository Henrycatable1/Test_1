# Product Backlog

## Purpose
Use this file to capture feature ideas, rule ideas, UX questions, and product decisions before asking an agent to implement them.

## How To Use
For each new idea:
1. Add it here first.
2. Clarify the product intent with discussion.
3. Decide whether it belongs in MVP now, later, or never.
4. Once agreed, promote it into `planning.md` or the relevant catalog doc.
